Your first dashboard: containers, a fixed size and a filter action

Put two sheets on one dashboard, hold them in layout containers, fix the size so it looks the same on every screen and add a filter action so selecting a store bar filters the monthly line.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 1 Ankur Napa DesktopDesignCertification

Short answer

Select Dashboard > New Dashboard. In the Size section of the Dashboard pane choose Fixed size with a width and height, so it looks the same on every screen. Drag a Vertical container onto the canvas, then drop a title and your sheets inside it. Turn the bar chart into a filter with Dashboard > Actions > Add Action > Filter, source the bar sheet, target the line sheet and run it on Select. Selecting a store's bar now filters the line to that store. Selecting it again clears the filter.

What you will build

A one-page dashboard for a Harbour Goods regional manager. On top, a title. Below it, sales by store as a sorted bar chart. Under that, sales by month as a line. Select a store bar and the line shows only that store's months. Harbour Goods is the fictional retailer with six stores used across this site.

It uses the workbook from Your first workbook, built on harbour-goods-orders.csv: 60 orders from July to September 2026. If you skipped that step, build its two sheets first. It takes about twenty minutes.

Before you start

  • The two sheets, named Sales by store (Store Id on Columns, SUM(Sales) on Rows, sorted descending) and Sales by month (continuous MONTH(Order Date) on Columns, SUM(Sales) on Rows).
  • The Store Id filter that excludes ST-099, applied to both sheets.
  • Some words. A dashboard is a canvas that holds several sheets and objects at once. A layout container is an invisible box that arranges what you put in it, side by side (Horizontal) or stacked (Vertical). Tiled objects snap into a grid and never overlap; floating objects sit on top at a fixed position. An action is a rule that makes one part of a dashboard respond to what the reader does in another.

Steps

1. Create the dashboard and fix its size

  1. Select Dashboard > New Dashboard. A new tab opens with the Dashboard pane on the left.
  2. In the Size section, open the dropdown. Fixed size is the default. Pick a preset or choose Custom and set width 1200 and height 800.
  3. Name the tab Store manager view.

Why fixed: an Automatic dashboard stretches to the reader's window, so your careful layout reflows on a laptop and leaves gaps on a wide monitor. Fixed size looks the same everywhere. Range sits between the two, with a minimum and a maximum.

2. Add a container

  1. In the Objects section of the Dashboard pane, drag Vertical onto the empty canvas. It fills the space.
  2. Drag Text from Objects into the top of the container. Type Harbour Goods: sales by store, July to September 2026. Set it to 18 point.

3. Add the sheets

  1. Under Sheets in the Dashboard pane, drag Sales by store into the container, below the title. A grey shadow shows where it will land.
  2. Drag Sales by month into the container, below the bar chart.
  3. Select the container itself: select a sheet, then its More Options arrow in the top corner and Select Layout Container. Open the same arrow again and pick Distribute Evenly. The two charts now share the height equally.
  4. Look at the right edge. Tableau has added the Store Id filter card and any legends. Drag the filter card under the title, or delete it if the action in the next step is enough.

Open the Layout tab beside Dashboard in the left pane. The Item hierarchy there shows the tree: the dashboard, the tiled area, your vertical container and the objects inside. When a drop lands in the wrong place, this tree tells you where it went.

4. Add a filter action

  1. Select Dashboard > Actions. The Actions dialog opens.
  2. Select Add Action > Filter.
  3. Name it Store to month.
  4. Under Source Sheets, tick only Sales by store.
  5. For how the action runs, select Select. Tick Single-select only if you want one store at a time.
  6. Under Target Sheets, tick only Sales by month.
  7. For what happens when the selection is cleared, pick Show all values.
  8. Leave All Fields on. Select OK, then OK again.

There is a shortcut: select the bar chart on the dashboard, open its More Options arrow and choose Use as Filter. Tableau creates the same kind of action with "generated" in its name. Building it by hand once teaches you what the shortcut hides.

5. Try it

  1. Select the ST-003 bar. The line redraws for ST-003 only.
  2. Select the same bar again, or an empty part of the chart. The line returns to all stores.
  3. Select Presentation Mode on the toolbar (F7 on Windows) to see the dashboard as a reader will.

September with nothing selected is ₹854.05 lower than in the first workbook's check because the ST-099 order is filtered out here. The ₹2,899 order with the impossible date still sits under the null indicator. It belongs to ST-014.

Where this breaks

  • The action filters the wrong sheet. If you tick every sheet as a target, selecting a bar filters the bar chart itself and the other bars vanish. Target only the sheets that should respond.
  • Floating by accident. Hold Shift while dragging and an object floats instead of tiling. Floating objects ignore the container and overlap on smaller sizes. Check the Floating list in the Item hierarchy.
  • Fixed size on a phone. A 1200 by 800 dashboard is cramped on a phone. Use Device Preview at the top of the Dashboard pane to add a phone layout, rather than shrinking the desktop one.
  • Clearing the selection leaves the filter on. If you chose Leave the filter, the line stays filtered after the reader deselects. Readers think the data is missing. Show all values is the safer default.
  • Too many sheets. Every sheet is a query. Two or three charts load fast; twelve do not. Split a crowded dashboard into two.

Which chart when

A dashboard is only as clear as the charts on it. Before adding a third sheet, check its form against the site's chart chooser.

On the brewhouse floor

A brewery's production dashboard works the same way. Hectolitres by fermenter goes on top as a sorted bar. Gravity by day goes underneath as a line. A filter action from the bar to the line means the brewer selects FV-04 and sees only that tank's ferment, without a filter card full of tank numbers. Fix the size to the screen on the brewhouse wall, because that is the only screen most of the team will ever look at.
