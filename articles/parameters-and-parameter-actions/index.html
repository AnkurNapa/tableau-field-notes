Parameters and parameter actions: swap, target, what-if

Use parameters to let readers swap the measure, move a sales target and test a price change, then drive one from a click with a parameter action. Every number checked against the sample.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 2 Ankur Napa DesktopCertification

Short answer

A parameter is a single workbook value the reader can change: a number, a date, a string or a true or false. On its own it does nothing. It only acts when a calculation, a filter, a reference line or a Top N uses it. That is the whole design rule. Build the parameter, then build the calculation that reads it, then show the control. A parameter action sets the value when the reader selects a mark instead of using a control, which is how a dashboard starts to feel like an app.

What you will build

A Harbour Goods store bar chart that:

  • swaps between Sales, Units and Margin from a drop-down;
  • colours stores above or below a target the reader types in;
  • projects sales and margin for a price change between -10% and +10%;
  • highlights a store when you select its bar on a dashboard, through a parameter action.

Before you start

  • Tableau Desktop or Tableau Public.
  • The cleaned Harbour Goods orders, products (it holds the unit cost) and stores. The cleaned file has 55 orders.
  • Connect with Connect > To a File > Text file, choose the orders file and drag the other two onto the canvas.
  • Create two calculated fields with Analysis > Create Calculated Field:
// Sales
[Quantity] * [Unit Price] * (1 - [Discount])
// Margin
[Sales] - [Quantity] * [Unit Cost]

Steps

1. A measure swap

  1. In the Data pane select the drop-down arrow at the top right and choose Create Parameter.
  2. Name it Choose measure. Set Data type to String and Allowable values to List.
  3. Add three values: Sales, Units and Margin. Select OK.
  4. Create the calculation that reads it, Selected measure:
CASE [Choose measure]
  WHEN 'Sales'  THEN SUM([Sales])
  WHEN 'Units'  THEN SUM([Quantity])
  WHEN 'Margin' THEN SUM([Margin])
END
  1. Drag Store Id to Rows and Selected measure to Columns. Sort descending.
  2. Right-click Choose measure in the Data pane and select Show Parameter. The control appears on the right.

Change the title to <Parameters.Choose measure> by store with Worksheet > Show Title and the Insert menu in the title editor. A swap without a title that follows it is a trap for the reader.

2. A target the reader can move

  1. Create a parameter called Sales target: Float, Allowable values: All, current value 30000. Format it as a number with no decimals.
  2. Set Choose measure back to Sales.
  3. Right-click the Selected measure axis and select Add Reference Line. Set Value to Sales target and Label to Value.
  4. Create Above target:
[Selected measure] >= [Sales target]
  1. Drag it to Color. Show the parameter and type 25000, then 30000.

This only makes sense for Sales. In a real workbook, hide the target control when another measure is chosen or give each measure its own target.

3. A what-if price change

  1. Create a parameter called Price change %: Integer, Range, minimum -10, maximum 10, step size 1, current value 0.
  2. Create two calculations:
// Projected sales
SUM([Sales]) * (1 + [Price change %] / 100)
// Projected margin
[Projected sales] - SUM([Quantity] * [Unit Cost])
  1. Put them in a small text table beside the chart and show the parameter as a slider.

The model assumes every customer still buys at the new price. That is the point to say out loud. A what-if that cannot be challenged is a forecast in disguise.

4. A parameter action

  1. Create a string parameter called Selected store with Allowable values: All and current value ST-003.
  2. Create Is selected store:
[Store Id] = [Selected store]
  1. Put it on Color in place of Above target.
  2. Build a dashboard and drop the store chart on it.
  3. Select Dashboard > Actions > Add Action > Change Parameter.
  4. Choose the store sheet as the source, run the action on Select, set the target parameter to Selected store, the source field to Store Id and aggregation to None.
  5. For what happens when the selection clears, choose Keep current value.

Select a bar. The parameter changes and the colour follows. Any other sheet that uses Selected store, such as a product breakdown filtered with [Store Id] = [Selected store], follows too.

5. Parameters that refresh themselves

A parameter's list is normally fixed when you create it. Since version 2020.1, the Create Parameter dialog can fill its list from a field and set its current value from a field when the workbook opens, so a new store or the latest month appears without editing the parameter. The labels in the dialog may read When workbook opens or similar; check them in your version.

Where this breaks

  • The parameter is not connected. A parameter action does nothing visible unless the parameter is used in the view, a calculation or a reference line. Nor does a control.
  • Multiple marks, no aggregation. With aggregation set to None, selecting two stores with different ids makes the action skip. Pick an aggregation or design for one mark.
  • Swapping dimensions in a multi-fact model. Tableau's help warns that swapping dimensions with a parameter can fail silently in a multi-fact relationship model.
  • Parameters are global, not per user. On Tableau Server or Cloud each viewer's change lasts for their session. A saved custom view keeps it. It never changes the published default.
  • What-if is not a forecast. Price elasticity is not in the data. Say so in a caption.

On the brewhouse floor

A brewery planning next month's brew schedule can put the malt price in a parameter and the expected brewhouse efficiency in another. A projected cost per hectolitre calculation reads both, so the head brewer can ask "what if malt goes up 8% and we lose two points of efficiency?" in the meeting instead of after it. A parameter action on a fermenter map sets the selected tank and every other chart follows. The demand forecasting and what-if build uses the same pattern.
