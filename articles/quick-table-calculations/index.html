Quick table calculations: running total, share and growth

A quick table calculation is a calculation on the numbers already in your view. Add a running total, a percent of total and a year-over-year growth with two clicks each, then learn what each one is computed along.

Short answer

Right-click a green measure pill, point to Quick Table Calculation and pick one: Running Total, Difference, Percent Difference, Percent of Total, Rank, Percentile, Moving Average, YTD Total, Compound Growth Rate, Year Over Year Growth or YTD Growth. The pill gets a small triangle to show it is now a table calculation. The thing to understand is that a table calculation runs on the table of numbers Tableau has already drawn, after filters. It is computed along a direction, across or down. If that direction is wrong the answer is wrong without any error message.

What you will build

Three sheets for Harbour Goods, the fictional retailer used across this site:

  1. A running total of sales by month, January 2025 to September 2026.
  2. Each store's share of total sales.
  3. Quarter-by-quarter growth against the same quarter last year.

The data is dates-in-tableau.csv: 148 clean orders over 21 months for the six Harbour Goods stores. You need a file with more than one year in it for year-on-year growth, which is why this walkthrough does not use the one-quarter sample.

Before you start

  • Tableau Desktop, any edition, connected to the CSV, with the Sales field created:
[Quantity] * [Unit Price] * (1 - [Discount])
  • You should know discrete date parts from continuous date values. If not, read Dates done right first.
  • Two words. A table calculation is a calculation on the aggregated numbers in the view, not on the rows of data. Compute Using is the setting that tells it which direction to run in: Table (across), Table (down), a specific field or others.

Steps

1. Running total

  1. Name a sheet Running total. Drag Order Date to Columns, right-click it and select Month in the lower group of the menu, so the pill is green and reads MONTH(Order Date).
  2. Drag Sales to Rows. You get a monthly line that goes up and down.
  3. Right-click SUM(Sales) on Rows and select Quick Table Calculation > Running Total.
  4. The line now only climbs. Each point is the sum of every month up to and including it. The pill shows a small triangle.
  5. Right-click the pill and select Edit Table Calculation. The dialog shows how it is computed: along Table (across), which here means along the timeline. Close the dialog.

2. Percent of total

  1. New sheet: Share by store. Drag Store Id to Rows and Sales to Columns.
  2. Right-click SUM(Sales) and select Quick Table Calculation > Percent of Total.
  3. Drag Sales again onto Label on the Marks card, then right-click that label pill and apply Percent of Total to it as well. The bars now carry their share.
  4. Select the Sort Descending button on the toolbar.

Now try a filter. Drag Store Id to Filters and untick two stores. The remaining shares grow and still add to 100 per cent. A quick table calculation runs after the filter, on what is left. If you want each store's share of the whole company even when stores are filtered out, you need a level of detail expression, which comes later on the roadmap.

3. Year-over-year growth

  1. New sheet: Year on year. Drag Order Date to Columns. It arrives as YEAR(Order Date), blue. Leave it.
  2. Drag Order Date again to Rows, right-click it and select Quarter from the upper group, so it is blue and reads QUARTER(Order Date).
  3. Drag Sales to Text on the Marks card. You have a small crosstab: quarters down, years across.
  4. Right-click SUM(Sales) on the Marks card and select Quick Table Calculation > Year Over Year Growth.
  5. The 2025 column goes blank: there is no 2024 to compare with. The 2026 column shows growth for Q1 to Q3. Q4 2026 is blank because it has not happened yet.
  6. Right-click the pill, select Format and set the numbers to Percentage with one decimal place if Tableau has not.

4. Look under the hood

Right-click any table calculation pill and select Edit Table Calculation. You will see the calculation type, the direction it runs in and a preview highlight in the view. Change Compute Using on the year-on-year sheet to Table (down) and watch the numbers turn into nonsense: it now compares Q2 with Q1 inside the same year and calls it year on year. Set it back. That experiment is the most useful two minutes in this walkthrough.

Where this breaks

  • Wrong direction, no error. A table calculation never warns you that it is running down when it should run across. Check one number by hand, every time.
  • Moving a pill changes the answer. Swap Rows and Columns and Table (across) now points the other way. Pin it to a field instead: in Edit Table Calculation pick Specific Dimensions and tick Order Date.
  • Filters change the base. Percent of total and rank recompute after filters. That is often what you want and sometimes not.
  • Missing periods. Year over year compares with the previous period in the table. If a quarter has no orders, it is not in the table. The comparison jumps to the wrong quarter. Gaps in the data are gaps in the calculation.

Which chart when

A running total suits a line, a share suits a sorted bar and growth suits a crosstab or a bar with a zero line. For anything else, the site's chart chooser suggests a form.

On the brewhouse floor

A brewery tracks hectolitres brewed against an annual plan. A running total of monthly volume, laid over a straight line to the target, shows by July whether the year will land. Percent of total on volume by beer tells the owner that two brands carry most of the tanks. Year over year by quarter catches the summer lager slump before it becomes a winter cash problem. Same three clicks, a different cellar.
