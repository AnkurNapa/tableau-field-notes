Sets and set actions: top N, in or out and drill-down

Build a top three stores set, compare in against out, write a condition set, then use a set action to drill from stores into categories with one click.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 2 Ankur Napa DesktopCertification

Short answer

A set is a custom field that splits the members of one dimension into In and Out. You can fill it by hand, by a condition or by a Top N rule. Sets earn their place in three jobs: comparing a group against everyone else, feeding a calculation that treats members differently, and, with a set action, letting the reader change membership by selecting marks. That last one is how you build drill-downs and "compare these to the rest" dashboards without a single parameter.

What you will build

  • A Top 3 stores set and an in or out comparison of their sales.
  • A condition set of busy stores, defined by order count.
  • A store list that expands into categories when you select a store, driven by a set action.

Before you start

  • Tableau Desktop or Tableau Public.
  • The cleaned Harbour Goods orders, products and stores. The cleaned file holds 55 orders.
  • Connect with Connect > To a File > Text file, choose the orders file and drag the other two onto the canvas.
  • Create Sales with Analysis > Create Calculated Field:
[Quantity] * [Unit Price] * (1 - [Discount])

Steps

1. A Top N set

  1. In the Data pane right-click Store Id and select Create > Set.
  2. Name it Top 3 stores.
  3. Open the Top tab, choose By field, then Top, 3, Sales, Sum. Select OK.

The set appears in the Data pane under its own heading with a Venn icon.

2. In against out

  1. Drag Top 3 stores to Rows. It shows two rows: In and Out.
  2. Drag Sales to Columns.
  3. Right-click SUM(Sales), select Quick Table Calculation > Percent of Total and drag Sales to Label to show both.

To list the stores inside each group, drag Store Id to Rows after the set. To show only the members, drag the set to Filters instead; it filters to In by default.

3. A condition set

  1. Right-click Store Id and select Create > Set again. Name it Busy stores.
  2. Open the Condition tab, choose By formula and enter:
COUNTD([Order Id]) >= 10
  1. Select OK, then drag Busy stores to Color on the store bar chart.

This quarter the busy stores and the top three by sales are the same three. Change the threshold to 8 and Mumbai joins the busy set but not the top three. Sets with different definitions agreeing once is a coincidence to note, not a reason to merge them.

4. Combine two sets

Select both sets in the Data pane, right-click and choose Create Combined Set. The options are all members in both sets, shared members in both sets or members in one set less those shared. "Busy but not top three" is the third. With the threshold at 8, it holds only ST-011.

5. A set action drill-down

  1. Create a third set on Store Id called Expanded store. On the General tab tick nothing. It starts empty.
  2. Create a calculated field called Category drill:
IF [Expanded store] THEN [Category] END
  1. New sheet. Drag Store Id then Category drill to Rows and Sales to Text. Every store shows one row with a blank (Null) category.
  2. Right-click the Category drill header and select Hide Field Labels for Rows if you want a tidy look.
  3. Build a dashboard with this sheet on it.
  4. Select Dashboard > Actions > Add Action > Change Set Values.
  5. Set the source to the store sheet, run the action on Select and choose Expanded store as the target set.
  6. Choose Assign values to set for running the action and Remove all values from set for clearing the selection.

Select ST-003. Its row opens into four categories. Select empty space and it closes again. The calculation reads the set; the action only changes who is in it.

After selecting ST-003 in step 5 the drill rows read: Electronics 14,562.60, Outdoor 14,032.20, Kitchen 6,970.05 and Home 5,307.15. They add to the store's 40,872.00.

Where this breaks

  • Top N sets ignore your dimension filters. A Top N set is computed before ordinary dimension filters, like the Top N filter in the order of operations. Filter to one region and the set still holds the company top three. Put the region filter in context.
  • The target set must be used. A set action changes membership, but if no shelf, calculation or Marks card uses the set, nothing visible happens.
  • Add and Remove change the definition. Choosing Add values to set or Remove values from set rewrites the set's General tab. That differs from the Add to and Remove from options in a tooltip, which apply after the set's condition.
  • Stories. Set actions do not work in stories.
  • Sets live on one dimension. A set of store and category pairs needs a set on a combined field, which is rarely worth the confusion. Two sets and a combined set usually read better.

On the brewhouse floor

A brewery's sales lead wants to see the ten pubs that pour most of the flagship pale ale against every other account. A Top 10 set on account, with In and Out on Rows, shows how much volume rides on those ten. A condition set on "fewer than two orders in 60 days" flags accounts going quiet. A set action on a map lets the rep select a cluster of pubs and see their keg returns beside it, which is the conversation before the delivery run, not after.
