Shelves, the Marks card and Show Me

Every Tableau worksheet is built from the same parts: the Columns and Rows shelves, the Filters shelf and the Marks card. Learn to read any viz from those parts and when Show Me helps.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 0 Ankur Napa DesktopCertification

Short answer

A Tableau worksheet is a sentence you build by dragging fields onto shelves. Columns and Rows decide the structure: what goes across and what goes down. The Marks card decides how each mark looks: its type, colour, size, label, detail and tooltip. The Filters shelf decides which rows take part at all. Show Me is a menu of ready-made chart types that rearranges your pills for you. Learn to read those four places and you can reverse-engineer any viz on Tableau Public in a minute.

The idea in one picture

Some words first:

  • A shelf is a strip you drop pills on. Columns, Rows, Filters and Pages are shelves.
  • A mark is one drawn thing in the view: one bar, one dot, one line point, one text cell.
  • The level of detail is how many marks there are. Every blue (discrete) dimension in the view, on any shelf or on the Marks card, splits the marks further.
  • The Marks card sits left of the view. Its dropdown sets the mark type. Its buttons, Color, Size, Label, Detail and Tooltip, encode more fields onto each mark. Shape, Path and Angle appear for some mark types.

Tableau's help lists the mark types as Automatic, Bar, Line, Area, Square, Circle, Shape, Text, Map, Pie, Gantt Bar, Polygon and Density. On Automatic, Tableau picks for you: one dimension and one measure give bars, a date and a measure give a line and dimensions on both shelves give text. Automatic never picks Pie.

A ten-minute tour

Use Tableau Desktop (any edition) and harbour-goods-orders.csv, the shared sample of 60 orders from the fictional retailer Harbour Goods.

  1. Connect to the CSV with Connect > To a File > Text file and select Sheet 1.
  2. Drag Store Id to Columns and Quantity to Rows. Tableau draws bars. Look at the Marks card: the dropdown says Automatic and the icon is a bar.
  3. Drag Product Id onto Color on the Marks card. Each bar splits into coloured segments, one per product. The level of detail went up: more marks, same shelves. Hover over a segment and read the tooltip.
  4. Drag Product Id off Color and onto Detail. The bars look whole again, but hover: each bar is now several stacked marks. Detail adds marks without changing how they look.
  5. Drag Product Id out of the view entirely. Then drag SUM(Quantity) from Rows onto Label while holding Ctrl (Option on Mac) to copy it. Numbers appear on the bars.
  6. Drag Discount to the Filters shelf. A dialog asks how to treat it: pick All values, then set the range to 0 to 0.05 and select OK. Orders with a ten per cent discount drop out. The bars shrink. Filters remove rows before Tableau draws.
  7. Open Show Me from the top right of the toolbar. The chart types it can build from what is in the view are in colour. The one it recommends has an orange outline. Hover over a greyed type to read what it needs, such as one or more dimensions and one or more measures.
  8. Select packed bubbles in Show Me. Look at the shelves: Tableau has moved your pills to the Marks card. Press Ctrl+Z (Command+Z on Mac) to go back to bars. Show Me only moves pills; you can always read what it did.
  9. Go to Tableau Public, open any viz with a download option and open it in Desktop. Read it shelf by shelf: what is on Columns, Rows, the Marks card and Filters. That habit is the whole skill.

What people get wrong

  • "Show Me knows the best chart." It knows which charts are possible with the fields you selected. It does not know your question. It recommends a line for a date and a measure because that is usually right, not because it read your brief.
  • "Colour is decoration." Colour is a field. A blue field on Color adds marks and splits the view. A green field gives a gradient and does not add marks.
  • "Detail does nothing." Detail changes the level of detail, which changes every aggregation in the view. It is often why a number looks wrong.
  • "Filters only hide things." A filter on the Filters shelf removes rows before aggregation. Totals change. Hiding a header (right-click > Hide) does not remove rows.
  • "I changed the mark type and the chart broke." Forcing Pie or Line on the wrong pills gives nonsense. Go back to Automatic first, then change one thing at a time.

On the certification

This step maps to the Tableau Desktop Foundations exam guide in two places. Domain 2, Exploring and Analyzing Data, includes 2.1.1 to 2.1.9 (bar, line, scatterplot, map, stacked bar, highlight table and crosstab charts, all built from shelves and the Marks card) and 2.2.4 (add a filter to a view). Domain 3, Sharing Insights, includes 3.1.1 (use colour from the Marks card), 3.1.3 (format marks as shapes), 3.1.5 (change the size of marks) and 3.1.6 (show and hide legends). The exam guide does not name Show Me, but every chart objective can be built with it.

Next on the roadmap

You now know the parts. Next, build something with them: Your first workbook connects the same CSV and builds a bar chart, a line chart and a filter you can hand to someone. If the pill colours still confuse you, go back to Blue pills and green pills.

On the brewhouse floor

Read a fermentation chart the same way. Columns holds the reading date, continuous. Rows holds AVG(Gravity). Tank number sits on Color, so each fermenter gets its own line. Batch number sits on Detail so a reused tank does not join two brews into one line. Put beer style on the Filters shelf and the lager tanks drop out while the ales stay. Four shelves, one cellar.
