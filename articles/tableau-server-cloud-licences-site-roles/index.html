Server, Cloud and the three licences

Tableau Server is the one you run. Tableau Cloud is the one Salesforce runs. Both sell the same three licences: Creator, Explorer and Viewer. A site role decides what each person can actually do.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 0 Ankur Napa ServerCloudCertification

Short answer

Tableau Server and Tableau Cloud do the same job. They hold published workbooks and data sources, run extract refreshes and decide who sees what. The difference is who runs the machines. You install, patch and back up Tableau Server on your own hardware or cloud account. Salesforce runs Tableau Cloud for you and upgrades it on its own calendar.

Both sell the same three licences. A Creator can connect to new data and build anything. An Explorer can build from data that is already published. A Viewer can look, filter and subscribe. The licence is the ceiling. The site role you give a person sits under that ceiling and is what Tableau actually checks.

The idea in one picture

"Limited" means the person can publish workbooks built on data sources that already exist, but cannot connect to new data or create a data source. That single line is where most licence arguments end.

A ten-minute tour

You do not need a server to see any of this. A Tableau Cloud trial is enough. Check the sign-up page for the current trial length.

  1. Sign in to your trial site. The left pane shows Home, Explore and the other pages. As the person who made the site you are a Site Administrator Creator.
  2. Select Users. Each row shows a Site Role column. Open the add users dialog (the button may read Add Users or Add Users by Email) and look at the site role list. You will see the roles from the picture above, with a line under each that says what it can do.
  3. Add one test user as Viewer and one as Explorer. Use addresses you control.
  4. Select Explore > Default project. That project exists on every site. Open its ... menu and choose Permissions. Look at the rule for All Users. This is what every new person inherits.
  5. Sign in as your Viewer in a private window. Open any sample view. Notice what is missing: no Edit button, no New > Workbook.
  6. Sign in as the Explorer. Edit now appears on a view. You can change and explore. Saving is a different matter. That depends on whether the role is Explorer or Explorer (can publish).

That is the whole licence model in practice. Everything after this on the roadmap builds on it.

What people get wrong

  • "Explorers can publish anything." Only Explorer (can publish) and Site Administrator Explorer can publish. Even they publish only on top of data that is already published. They cannot connect to a database or a file from the browser. That is the Creator line.
  • "Viewers can download the data." Viewers can download images and summary data if permissions allow. They cannot connect to data, create content, set data-driven alerts or be given an admin profile.
  • "Permissions can promote someone." They cannot. The site role is the ceiling. An Allow rule on a project does nothing for a capability the site role does not include.
  • "Server Administrator exists on Cloud." It does not. On Cloud the highest role is Site Administrator Creator. A site admin there can always manage users. On Server, the server admin decides whether site admins may manage users.
  • "Unlicensed is a cheap licence." It is not a licence at all. An Unlicensed user cannot sign in. People land there when licences run out, when an import says so or when a product key expires. They still own their content, which matters when you tidy up later.
  • "Cloud is just Server someone else hosts." Mostly, but not entirely. You lose the TSM command line and direct access to the repository database. You gain Admin Insights and automatic upgrades. Tableau Pulse is Cloud only. That trade decides real projects. It is the Level 4 step.

On the certification

This step maps to the Tableau Server administrator credential. As of October 2026 it sits in the Salesforce certification programme as Salesforce Certified Tableau Server Administrator, the successor to the older Tableau Server Certified Associate. I could confirm the name but not the current objective list, so check the exam guide on Trailhead Academy before you study. Site roles and licences are the ground floor of any administrator exam, so learn them cold.

On the brewhouse floor

A brewery maps onto the three licences without much argument. The brewer who builds the fermentation dashboard from the tank log needs Creator. The quality lead who slices that dashboard by tank and wants to save her own version needs Explorer (can publish). The sales team and the owner, who only read the weekly hectolitres and the sell-through numbers, are Viewers. Pay for the role each person plays on a normal Tuesday, not the one they might play someday.
