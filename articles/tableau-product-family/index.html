The Tableau family in one picture

Tableau is a family of products, not one app. This maps Desktop, Prep, Server, Cloud, Public, Pulse and Next, plus the free ways in. It also tells a beginner what to install first.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 0 Ankur Napa DesktopPrepServerCloudPublicPulseCertification

Short answer

Tableau is a family of products that share one way of building charts. You build in Tableau Desktop, clean data in Tableau Prep, share through Tableau Server or Tableau Cloud and show work to the world on Tableau Public. Tableau Pulse watches metrics and sends you a digest. Tableau Next is the newer agent-first platform that runs on Salesforce. If you are starting from zero, install Tableau Desktop Public Edition. It is free, it is the same canvas the certification tests and nothing you learn on it is wasted.

The idea in one picture

Think of it as a workshop with a few rooms. Each room does one job.

A few words you will meet everywhere:

  • A viz is any chart, map or table you build in Tableau.
  • A workbook is the file that holds your vizzes. It saves as .twb, or as .twbx when the data travels inside it (a packaged workbook).
  • A data source is the connection to your data: a CSV, a spreadsheet or a database.
  • An extract is a snapshot of the data saved in Tableau's own .hyper format. A live connection queries the source every time instead.

Here is the family in one table.

ProductWhat it isWho uses itCost to a learner
Tableau DesktopThe app you build vizzes and dashboards in, on Windows or MacAnalysts, developersPublic and Free editions cost nothing; Professional needs a paid licence
Tableau Prep BuilderA visual tool to clean, join and reshape data into a flowAnalysts who own messy dataComes with a Creator licence; free through Tableau for Students

The three Desktop editions

Tableau's help now splits Desktop into three editions. The row limits and rules below come from the official comparison page.

EditionGood forLimits
Desktop Public EditionLearning, public data, a portfolioNot for commercial use; about 15 million rows; a short list of file connectors; publishes only to Tableau Public
Desktop Free EditionPrivate data on your own machineCannot publish to Tableau Server, Tableau Cloud or Tableau Public
Desktop Professional EditionWork inside a companyPaid licence; connects to everything and publishes to Server or Cloud

The free ways in

  • Tableau Desktop Public Edition plus a Tableau Public profile. Download the app from the Tableau Public site, sign up with an email and you are building in minutes. You can save locally and publish to your profile when you are ready.
  • Tableau for Students. Students at accredited schools get a free licence for Tableau Desktop and Tableau Prep Builder, valid for one year from activation and renewable while you study.
  • Tableau for Teaching. Instructors get free renewable licences, can request keys for a class and are the only route to a classroom Tableau Cloud site.
  • A Desktop trial. Tableau has long offered a free trial of the paid Desktop. Use it when you need a connector the Public Edition lacks.

Which one to install first

Install Tableau Desktop Public Edition and create a Tableau Public profile. Three reasons:

  1. It is free and needs no company approval.
  2. The canvas is the same Desktop the certification tests. Shelves, pills, the Marks card and Show Me all work the same way.
  3. Your practice becomes a portfolio. Employers look at Tableau Public profiles.

The catch is privacy. Anything you publish to Tableau Public is public. Use the sample files on this site or any open data. Never use a work file. If you are a student, apply for Tableau for Students too, so you have Prep and the full Desktop for private work.

A ten-minute tour

  1. Open Tableau Public in a browser. Select Viz of the Day or search for any topic you like. Interact with a dashboard: hover over a bar, select a filter. This is what Server and Cloud users see too.
  2. On any viz, look for the download button in the toolbar at the bottom. Some authors allow you to download the workbook. Open one in Desktop Public Edition later and see how it was built.
  3. Install Desktop Public Edition. On the start page, look at the Connect pane on the left. That list of file types is the Public Edition's connector list. It is shorter than the paid edition's.
  4. Under To a File, select Text file and pick harbour-goods-orders.csv. This is the shared sample on this site: 60 orders from Harbour Goods, a fictional retailer with six stores across India.
  5. Select Sheet 1 at the bottom. You are on the canvas. Do not build anything yet. Notice the Data pane on the left, the Columns and Rows shelves at the top and the Marks card. The next two steps on the roadmap explain each one.

What people get wrong

  • "Tableau Public is a cheap Tableau Cloud." It is not. Tableau Public has no private sharing. If a manager says "just put it on Public", that is a data leak.
  • "Tableau Server and Tableau Cloud are different tools." They are the same sharing experience. The difference is who runs the machines and who does the upgrades.
  • "Prep replaces Desktop." Prep shapes data. Desktop builds vizzes. Most people use Desktop for a year before they need Prep.
  • "Pulse is a dashboard." Pulse is a metric with a definition, a time window and a digest. It suits people who will never open a dashboard.
  • "I will type a question and get a chart." Ask Data is retired. The natural-language features now sit in Tableau Agent and Pulse.
  • "I need Tableau Next to learn Tableau." You do not. Tableau Next is built for Salesforce customers working with AI agents. Start with Desktop.

On the certification

This step maps to the Salesforce Certified Tableau Desktop Foundations exam, the entry certification that replaced Desktop Specialist. As of October 2026 the exam guide lists 40 scored questions, 70 minutes, a 48 per cent pass mark in English, a US$75 fee and no prerequisites. Its four domains are Connecting to and Preparing Data (23 per cent), Exploring and Analyzing Data (37 per cent), Sharing Insights (25 per cent) and Understanding Tableau Concepts (15 per cent). The product map here supports objective 1.1.2 (live connections against extracts) and 3.3.1 (sharing a workbook, including publishing to Tableau Server). The guide says it tests on version 2022.3, so a current Public Edition covers everything it asks.

On the brewhouse floor

A small brewery can use the same map. The head brewer builds a fermentation dashboard in Desktop from the tank log. Prep cleans the brew sheets that three shifts fill in three different ways. Tableau Cloud shares the dashboard with the owner, who never logs on, so a Pulse metric on hectolitres packaged per week lands in her inbox on Monday. The public tasting-notes viz for the taproom goes on Tableau Public, because that one is meant to be seen.
