Tableau AI without the hype: Pulse, Agent, Explain Data and MCP

Four things get called Tableau AI and they do different jobs. This tour separates Tableau Pulse, Tableau Agent, Explain Data and the Tableau MCP server, says where each runs and what it needs. It also places Tableau Next beside them.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 0 Ankur Napa AIPulseMCPClaude

Short answer

"Tableau AI" is four different things with one badge. Explain Data is statistics, not generative AI. It has been in Desktop since 2019. Tableau Pulse watches metrics on Tableau Cloud and sends you a digest. Tableau Agent is the authoring assistant that builds views and writes calculations from a sentence. The Tableau MCP server is an open-source bridge that lets an outside AI client, Claude included, query your published data and content through the Tableau APIs. Tableau Next sits apart from all four: it is a separate analytics product on the Salesforce platform with its own semantic layer. Ask Data was retired in Tableau Cloud in February 2024 and in Tableau Server 2024.2, so ignore any tutorial that still shows it.

Two lines in that table cause most of the confusion. Pulse is Cloud only: the Tableau MCP docs say plainly that Tableau Server cannot use Pulse at this time. And Tableau Agent on Cloud goes through the Einstein Trust Layer, while on Server 2025.3 and later it calls an LLM provider you configure with your own key.

A ten-minute tour

You need a Tableau Cloud trial site for most of this. Tableau Public covers only Explain Data.

  1. Explain Data. Open any published viz with a bar chart. Hover over a bar and select the Data Guide icon in the tooltip menu. On Tableau Public the icon is a lightbulb. Read the explanations in the Data Guide pane. Note that each one is a statistical model of that single mark. The help page says it outright: it cannot identify causes.
  2. Tableau Pulse. On the trial site open Tableau Pulse from the left navigation. If it is missing, a site administrator turns it on under Settings > Tableau Pulse > Deployment > Turn on Tableau Pulse. Browse the metrics and open one. Look at the digest preferences under your user icon: daily, weekly or monthly, by email or Slack.
  3. Tableau Agent. Open a workbook in web authoring and look for the Tableau Agent icon next to Show Me. If it is not there, the site lacks Tableau+ or AI in Tableau is off. Type "sum of sales by region as a bar chart" and watch it build the view. Then open a calculated field and ask it to explain the formula.
  4. The MCP server. You do not need to install anything to see what it offers. Read the tool list on the Tableau MCP documentation site: list-datasources, get-datasource-metadata, query-datasource, list-workbooks, get-view-data, get-view-image, the Pulse tools and more. Each tool calls a documented Tableau API as the signed-in user.
  5. Tableau Next. Read the Tableau Next product page and note the words Data 360 and Tableau Semantics. If you work only in Tableau Cloud or Server, this is a separate purchase, not a menu you have missed.

Where Claude fits

Claude does not run inside Tableau Desktop or inside Tableau Agent. Claude reaches Tableau from the outside in three ways. This roadmap teaches each one:

  • As a calculation partner in a chat window. You paste field names and ask for an LOD or a table calc, then you check it. No connection to Tableau at all.
  • Through the Tableau MCP server, from Claude Desktop, Claude Code or the Tableau connector in Claude. Claude then asks Tableau questions with your permissions.
  • Through Claude Code writing scripts against the REST API and Tableau Server Client, or editing workbook XML on a copy.

What people get wrong

  • "Explain Data is AI, so it is guessing." It is a statistical model. It is still not a cause. "You are the expert on your data" is Tableau's own line.
  • "Pulse is in Tableau Server." Not in October 2026. Pulse is a Tableau Cloud feature.
  • "Tableau Agent is ChatGPT in Tableau." On Cloud it runs through the Einstein Trust Layer with zero data retention and optional PII masking. On Server you choose the provider: OpenAI, or Azure OpenAI from 2026.2. Data protection on the provider's side is your job.
  • "The MCP server gives the AI access to everything." It acts as one identity. With a personal access token it sees what you see. With the hosted server each person signs in with OAuth and sees what they see. Scope it further with INCLUDE_TOOLS and the tool scoping variables.
  • "The old natural-language tool still works." Ask Data was retired. The help pages that mention it now say so.
  • "AI in Tableau costs credits per question." Since October 2025 AI in Tableau no longer consumes Einstein Request credits. Licensing still decides who gets which feature.

On the brewhouse floor

A brewery could use all four in one week without noticing. Explain Data on a bar that shows one tank losing more beer than the others. A Pulse metric on hectolitres packaged that lands in the head brewer's inbox each Monday. Tableau Agent to draft the calculation for brewhouse yield. Claude over MCP to answer "which fermenter ran warmest last month" from the published data source. The useful habit is the same in every case: know which tool is doing statistics, which is doing language and which one is only fetching numbers. My brewery production and yield dashboard shows the yield side.
