Charts beyond Show Me: dual-axis, bullet, Pareto, waterfall

Build four charts by hand that Show Me either cannot make or makes badly: a dual-axis sales and margin chart, a bullet chart against targets, a Pareto and a waterfall.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 2 Ankur Napa DesktopTable calcsDesignCertification

Short answer

Show Me picks a chart from the fields you select. It is a good start and a poor finish. Reviews ask for a bar with a rate line over it, actual against target, the 80/20 split and a bridge from one total to the next. All four are built from the same moves: a dual axis, a reference line or band, a table calculation and a mark type change. Learn those four moves and the rest is practice.

What you will build

On Harbour Goods data for July to September 2026:

  1. A dual-axis chart of monthly sales as bars with margin percentage as a line.
  2. A bullet chart of each store's sales against its quarter target.
  3. A Pareto chart of products: bars sorted by sales with a cumulative percentage line.
  4. A waterfall that builds total sales from the four categories.

Before you start

  • Tableau Desktop or Tableau Public.
  • Download the cleaned Harbour Goods orders (55 orders), products, stores and store targets by category and month (72 rows).
  • Connect with Connect > To a File > Text file, choose the orders file and drag products and stores onto the canvas. Drag the targets file onto the canvas and drop it beside the stores table, so it relates to stores on Store Id. Why that matters is the subject of relationships and multi-fact models.
  • Create three calculated fields with Analysis > Create Calculated Field:
// Sales
[Quantity] * [Unit Price] * (1 - [Discount])
// Margin
[Sales] - [Quantity] * [Unit Cost]
// Margin %
SUM([Margin]) / SUM([Sales])

Steps

1. Dual axis: sales bars with a margin line

  1. Drag Order Date to Columns and set it to the continuous Month (the second Month in the right-click menu, green pill).
  2. Drag Sales to Rows, then Margin % to Rows to its right. Two charts stack side by side.
  3. Right-click the Margin % pill and select Dual Axis.
  4. On the Marks card, set SUM(Sales) to Bar and AGG(Margin %) to Line.

Do not select Synchronize Axis here. The left axis is rupees and the right axis is a percentage. Synchronising them would flatten the line to zero. Synchronise only when both axes measure the same thing in the same unit. Label the right axis clearly and start it near the data, not at zero, or a three-point swing in margin disappears.

2. Bullet chart: actual against target

  1. New sheet. Drag Store Id from the stores table to Rows and Sales to Columns. Each table has its own copy of the id; Tableau adds the table name in brackets to the second one it finds. The stores copy is the one both facts share.
  2. Drag Target Sales from the targets table onto Detail.
  3. Right-click the Sales axis and select Add Reference Line. Choose Per Cell, set the value to SUM(Target Sales), aggregation Sum. Make the line a short dark stroke.
  4. Add a second reference item, this time a Distribution, also Per Cell. Set the values to percentages of SUM(Target Sales): 60 and 80. Shade it light grey. Tick Fill Below if you want the classic three-band look.
  5. Narrow the bars with Size so the target line shows past them.

Show Me also has a bullet graph. It assigns the first measure you selected to the bar, so it often draws target as the bar and sales as the line. Building it yourself means you choose.

3. Pareto: which products make 80% of sales

  1. New sheet. Drag Name (from products) to Columns and Sales to Rows.
  2. Right-click Name and select Sort. Sort by Field, Descending, Sales, Sum.
  3. Drag Sales to Rows again. Right-click the second pill and select Quick Table Calculation > Running Total.
  4. Right-click it again, select Edit Table Calculation, tick Add secondary calculation and choose Percent of Total. Check that both use Table (across).
  5. Right-click the second pill and select Dual Axis. Set the first to Bar and the second to Line.
  6. Add a constant reference line at 0.8 on the right axis.

The line crosses 80% at the fifth product. Five of eight products carry the quarter.

4. Waterfall: from categories to the total

  1. New sheet. Drag Category to Columns and Sales to Rows.
  2. Sort Category descending by Sales.
  3. Right-click SUM(Sales) and select Quick Table Calculation > Running Total.
  4. Set the mark type to Gantt Bar.
  5. Create Negative sales:
-SUM([Sales])
  1. Drag it to Size. Each Gantt bar now hangs from its running total down to where the previous step ended.
  2. Select Analysis > Totals > Show Row Grand Totals to add the final column.

Colour by Category, or by a sign calculation if some steps are negative, such as returns or write-offs.

Where this breaks

  • Dual axis with mismatched marks. When both measures share one Marks card setting, Tableau may draw both as lines. Set each card separately.
  • The bullet target counted twice. If targets join to orders instead of relating to stores, SUM(Target Sales) inflates. Relate at the target's own grain.
  • Pareto under a filter. The percent of total is computed on what survives dimension filters. Filter to one region and the 80% line describes that region only, which may be what you want, but say so in the title.
  • Waterfall sort. The running total follows the sort. Change the sort and every bar moves.
  • Colour alone. A red and green waterfall fails readers with colour vision deficiency. Use labels or a blue and orange pair; see accessible dashboards.

Next on the roadmap

The bullet chart needed a second table at a different grain. That is the next step: Relationships and multi-fact models.

On the brewhouse floor

Each of these charts has a brewery twin. A dual axis puts hectolitres packaged as bars and yield percentage as a line. A bullet chart shows each beer's monthly volume against plan. A Pareto of downtime reasons on the packaging line usually shows two causes, often changeovers and label jams, behind most lost minutes. A waterfall walks cost per hectolitre from malt to hops to energy to packaging. The packaging line OEE build uses the downtime Pareto.
