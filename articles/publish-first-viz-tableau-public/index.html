Publish to Tableau Public: your first viz and a profile people follow

Build a sorted bar chart of net sales by store from a fictional retailer's CSV, publish it to Tableau Public, write a description that gets found and set up a profile worth following.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 1 Ankur Napa PublicDesktop

Short answer

Build in Tableau Desktop Public Edition, save a local copy first, then publish to Tableau Public. Before you share the link, do three things on the viz page: write a description that says what the reader learns, set a permalink and decide whether others may download it. Then spend ten minutes on your profile. People follow profiles, not single vizzes.

What you will build

One worksheet: net sales by store for Harbour Goods, a fictional retailer and distributor with six stores across India. The data covers 55 orders placed between 2 July and 29 September 2026. You will add one calculated field, sort the bars and publish the result to your own Tableau Public profile.

Download the data: harbour-goods-orders-clean.csv. Each row is one order with order_id, order_date, store_id, product_id, quantity, unit_price in rupees and discount as a fraction (0.05 is five per cent).

Harbour Goods is invented, which is the point. This is data you are allowed to make public. Your employer's data is not, however tidy it looks.

Before you start

  • Tableau Desktop Public Edition, free from the Tableau Public site, on Windows or Mac. Desktop Professional Edition works too. Desktop Free Edition does not: it cannot save to Tableau Public.
  • A Tableau Public account. Sign up on public.tableau.com and verify your email. The activation link is valid for 48 hours; after that, use Forgot your password to activate.
  • Ten minutes of honesty about the data. Anything you publish can be found by search and downloaded by default.

Steps

1. Connect to the CSV

  1. Open Tableau Desktop Public Edition.
  2. In the Connect pane, under To a File, select Text file.
  3. Choose harbour-goods-orders-clean.csv and select Open.
  4. Check the preview grid on the Data Source page. You should see seven columns. quantity, unit_price and discount should show a number icon (#). If any of them shows Abc, select the icon above the column and choose Number (decimal).
  5. Select Sheet 1 at the bottom left.

2. Create Net Sales

  1. Select Analysis > Create Calculated Field.
  2. Name it Net Sales and enter:
[quantity] * [unit_price] * (1 - [discount])
  1. Select OK. Net Sales appears under the measures in the Data pane.

This is a row-level calculation. Tableau works out net sales for each order, then the view adds them up as SUM(Net Sales).

3. Build the chart

  1. Drag store_id to Rows. It is a discrete dimension, so it shows as a blue pill and gives one header per store.
  2. Drag Net Sales to Columns. It becomes the continuous green pill SUM(Net Sales) and draws one horizontal bar per store.
  3. Select Sort Descending on the toolbar so the biggest store is at the top.
  4. Drag Net Sales from the Data pane onto Label on the Marks card to print the value on each bar.
  5. Double-click the sheet title and write a title that states the finding, not the chart type: Bengaluru South led Harbour Goods sales in July to September 2026.
  6. Rename the sheet tab to Net sales by store. Sheet names show on Tableau Public and in view counts.

4. Save a local copy first

Select File > Save As and save a packaged workbook (.twbx) on your machine. Tableau Public is not a backup. If you ever delete the online copy, nobody can restore it.

5. Publish to Tableau Public

  1. Select Server > Tableau Public > Save to Tableau Public. In some Public Edition builds the label may read File > Save to Tableau Public As.
  2. Sign in with your Tableau Public account.
  3. Name the workbook something a stranger would search for: Harbour Goods net sales by store, Q3 2026. Avoid Book1 and test final.
  4. Select Save. Tableau creates an extract of the data, uploads it and opens the viz in your browser.

6. Finish the viz page

  1. On the viz page, select Edit Details.
  2. Write a description of two or three sentences. Say what the data is, where it came from and what the reader should notice. For this one: "Fictional retail data for practice. Net sales by store for 55 orders, July to September 2026. Bengaluru South sold a quarter of the total."
  3. Add a permalink if offered, so the URL stays readable.
  4. Select the Settings icon in the viz toolbar. Under Allow Access, decide whether to keep Let others download or make a copy of this viz on. For practice data, leave it on. Downloads also expose the View Data table that screen-reader users rely on.
  5. Select Share under the viz to copy the link or the embed code.

7. Set up the profile

  1. Select your profile icon > My Profile > Edit Profile.
  2. Add a bio of one line that names your audience, for example "Retail and supply chain analytics in Tableau". Add your title, location and LinkedIn link.
  3. Tick Available for Hire if you are looking. It adds a Hire Me button that emails you enquiries.
  4. Hover over a picture placeholder to select Update profile picture, then select Customize Banner to set a colour and pattern.
  5. Hover over your best viz on the profile and select it as your featured viz.
  6. Follow ten authors whose work you admire. Their new vizzes then appear in your Recent Activity channel on the home page.

Then sign out, or open the viz in a private browser window. If you can see it there, so can everyone else. That is the real test.

Where this breaks

  • The numbers are text. If Tableau reads discount as a string, Net Sales errors. Change the data type on the Data Source page, not with a calculation.
  • Duplicate names overwrite. Publishing again with the same name and choosing to overwrite makes Tableau Public treat it as a new workbook. Its view count goes back to zero.
  • Renaming sheets lowers views. Views are counted per sheet. Rename or delete a sheet people have seen and the total drops.
  • Live connections do not publish. Tableau Public keeps extracts only. The one exception is Google Sheets, refreshed once every 24 hours.
  • The 15 million row cap. Public Edition and Tableau Public stop at 15 million rows. Aggregate before you publish if you are near it.
  • Web authoring on a phone. Creating or editing vizzes in the browser needs a desktop or laptop. Mobile devices are not supported for authoring.

Next on the roadmap

You have one viz on a profile. Next, put it in front of people with your first community challenge. When you have a handful of vizzes, A portfolio that gets you hired turns the profile into something a hiring manager reads in two minutes.

On the brewhouse floor

The same chart answers a question every small brewery asks: which taproom or account sold the most this quarter? Swap stores for outlets and net sales for litres sold. The sorted bar shows the outlet carrying the brewery. Publish that only with invented or public numbers; real outlet volumes are commercial secrets.
