Connect Claude to Tableau with the Tableau MCP server

Run the official Tableau MCP server from Claude Desktop or Claude Code, sign in with a personal access token or OAuth and ask a published data source a question. Then read the query Claude sent and check the answer.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 2 Ankur Napa MCPClaudeAIAPICloudServer

Short answer

The Tableau MCP server is an open-source Node.js program from Tableau that exposes Tableau's APIs as tools an AI client can call. Claude asks a question, picks a tool such as query-datasource. The server runs it against Tableau as you. There are two ways in. Tableau Cloud users can point Claude at the hosted server at https://mcp.tableau.com and sign in with OAuth. Anyone, Cloud or Server, can run it locally with npx and a personal access token. Either way Claude only sees what your Tableau identity can see. Read the query it sent before you believe the number it gives back.

Claude stays outside Tableau. Nothing here installs Claude in Tableau Desktop.

What you will build

A Claude Desktop or Claude Code session connected to your Tableau site through the Tableau MCP server, limited to the data source tools, that answers "which three stores sold most in July to September 2026" from the Harbour Goods Orders published data source.

Publish the data source first if you have not: Your first Pulse metric walks through it with first-pulse-metric-net-sales.csv. It works the same on Tableau Server.

Before you start

  • Node.js 22.7.5 or later for the local route. The package's engines field asks for it; one older page in the docs still says 18. Check with node --version.
  • A personal access token for the local route. In Tableau select your profile picture > My Account Settings > Personal Access Tokens, give it a name such as mcp-laptop and copy the secret. Tableau shows it once.
  • API Access on the data source. The query-datasource tool calls the VizQL Data Service, which needs the API Access capability. Without it you get a 403.
  • VizQL Data Service enabled. It is on in Tableau Cloud. Tableau Server administrators may need to enable it.
  • Your site's content URL, not its display name. It is the part after /site/ in the browser address bar.
  • The pod URL on Tableau Cloud, such as https://prod-xx-x.online.tableau.com, not the generic sign-in page.

Steps

1. Pick a route

Hosted, https://mcp.tableau.comTableau Cloud onlyOAuth, each person as themselvesTableau runs it

For a first build on Tableau Cloud the hosted route is the least work. Step 2 covers it. For Tableau Server, or when you want to see every setting, use step 3.

2. Hosted route (Tableau Cloud)

In Claude Code, run:

claude mcp add --transport http Tableau https://mcp.tableau.com

Start a session, type /mcp, select Tableau and choose Authenticate. A browser opens on your Tableau Cloud sign-in. claude mcp list confirms the connection.

In the Claude app the docs describe the same thing as a directory connector: Customize > Connectors > Add > Browse connectors, search for Tableau, select the Tableau Cloud connector and Connect to Claude. Directory labels change often, so the wording may differ slightly.

If you are a member of more than one site, OAuth is site scoped. Sign out of Tableau Cloud, sign in to the site you want, then authenticate again.

3. Local route with a PAT (Cloud or Server)

Claude Desktop. Open the config file. On macOS it is ~/Library/Application Support/Claude/claude_desktop_config.json; on Windows, %APPDATA%\Claude\claude_desktop_config.json. Settings > Developer > Edit Config opens it too. Add:

{
  "mcpServers": {
    "tableau": {
      "command": "npx",
      "args": ["-y", "@tableau/mcp-server@latest"],
      "env": {
        "SERVER": "https://<your-pod-or-server>",
        "SITE_NAME": "<site-content-url>",
        "PAT_NAME": "<pat-name>",
        "PAT_VALUE": "<pat-secret>",
        "INCLUDE_TOOLS": "datasource"
      }
    }
  }
}

Quit Claude Desktop fully and reopen it. The Tableau tools appear under the tools icon in a new chat.

Claude Code. The same server, added from the terminal:

claude mcp add tableau \
  -e SERVER=https://<your-pod-or-server> \
  -e SITE_NAME=<site-content-url> \
  -e PAT_NAME=<pat-name> \
  -e PAT_VALUE=<pat-secret> \
  -e INCLUDE_TOOLS=datasource \
  -- npx -y @tableau/mcp-server@latest

That writes to your local Claude Code config, not the repository. Do not put a PAT in a project-scoped .mcp.json that gets committed.

INCLUDE_TOOLS=datasource limits the server to three tools: list-datasources, get-datasource-metadata and query-datasource. Without it you get the whole catalogue: workbooks, views and images, Pulse, content search, projects and, depending on the version and feature flags, publishing. Start small and add groups when you need them. Leave SITE_NAME empty only for the default site on Tableau Server.

4. Ask the question

Using the Tableau tools, find the published data source called
"Harbour Goods Orders". Which three stores had the highest net sales between
1 July 2026 and 30 September 2026? Give store id, city and net sales. Show
me the exact query you sent.

Claude normally calls three tools in order. list-datasources finds the LUID of Harbour Goods Orders. get-datasource-metadata returns its fields. query-datasource sends a VizQL Data Service query. Expand each tool call in the chat and read it. The query should look like this:

{
  "fields": [
    { "fieldCaption": "Store Id" },
    { "fieldCaption": "City" },
    { "fieldCaption": "Net Sales", "function": "SUM", "sortDirection": "DESC", "sortPriority": 1 }
  ],
  "filters": [
    {
      "field": { "fieldCaption": "Order Date" },
      "filterType": "QUANTITATIVE_DATE",
      "quantitativeFilterType": "RANGE",
      "minDate": "2026-07-01",
      "maxDate": "2026-09-30"
    }
  ]
}

Check it worked

Expected answer for July to September 2026:

StoreCityNet sales
ST-003Bengaluru40,872.00
ST-019Delhi32,640.90
ST-014Pune29,266.75

The failure to watch for is a missing date filter. If Claude skipped it, or used a relative filter such as "last quarter" on a day when that means something else, the answer comes back as Pune 97,502.00, Delhi 89,056.95 and Bengaluru 74,476.05. Those are all-time totals and the order is different. The reply will sound just as sure. That is why the prompt asks for the query: you check the filters block, not the prose.

Second check: ask "What is total net sales for the same period?" It should be 153,065.80. If the three-store figures are right and the total is not, Claude has filtered differently between two calls in the same chat.

Where this breaks

  • 401 Unauthorized. Wrong server URL or site content URL, or the display name used instead of the PAT name. PATs also expire after 15 days unused by default.
  • 403 Forbidden. The identity lacks API Access on the data source.
  • One PAT, two clients. A PAT cannot hold two sessions at once. Signing in from Claude Desktop and Claude Code with the same token logs the first one out. Make one token per client.
  • Several Tableau servers configured. The client may send a call to the wrong one and get another site's data, an empty result or a 401. Name each server clearly and check which one answered.
  • Pulse tools on Server. Tableau Server cannot use Pulse, so exclude the pulse group there.
  • Field names. VizQL Data Service uses field captions. A calculation renamed in the published data source breaks prompts that used the old name.

On the brewhouse floor

Publish the fermentation log as a data source and Claude can answer "which fermenter took longest to reach terminal gravity in September" without anyone opening a workbook. Read the query it sent. If the date filter is missing it will happily compare this September's lagers with last winter's ales and sound certain about it. The model sees the log. The brewer knows FV-06 was out for a glycol repair for a fortnight. My distributor scorecard is the kind of published source that works well behind this.
