Your first workbook: a bar, a line and a filter

Connect a CSV of orders, write one calculation for sales, build a sorted bar chart by store and a monthly line chart, then add a filter that drives both. About forty minutes.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 1 Ankur Napa DesktopCertification

Short answer

Connect the CSV with Connect > Text file, check the field types on the data source page, then create one calculated field, Sales, from quantity, price and discount. Build a bar chart with Store Id on Columns and SUM(Sales) on Rows, sorted high to low. Build a line chart with a continuous month of Order Date on Columns. Add Store Id as a filter, apply it to both sheets and show it. You will also meet the first messy data most real files carry: a duplicate row, a blank, a negative quantity, a store that does not exist and a date that cannot exist.

What you will build

A two-sheet workbook for Harbour Goods, a fictional retailer and distributor with six stores across India. Sheet one answers "which store sold most last quarter?" Sheet two answers "did sales rise or fall month by month?" One filter lets the reader drop a store from both answers at once.

The data is harbour-goods-orders.csv: 60 order rows from July to September 2026. Each row has an order ID, a date, a store, a product, a quantity, a unit price in rupees and a discount as a fraction, so 0.05 means five per cent. There is no sales column. You will make one.

I chose a file with problems on purpose. Every orders export I have ever opened had at least one of them. A first workbook that pretends otherwise teaches the wrong habit.

Before you start

  • Tableau Desktop. Any edition works: Public, Free or Professional. The Tableau family map explains which to install.
  • The pill colours. If blue and green pills are new, read Blue pills and green pills first. It takes ten minutes.
  • Words used here. A workbook is the Tableau file. A sheet (or worksheet) is one viz inside it. A calculated field is a new column you define with a formula. A filter decides which rows take part.

Steps

1. Connect to the CSV

  1. Open Tableau Desktop. On the start page, under Connect > To a File, select Text file.
  2. Pick harbour-goods-orders.csv and select Open.
  3. The data source page opens. The top shows the file as a table. The bottom shows a grid of the first rows.
  4. Top right, leave Connection set to Live. Live means Tableau reads the file every time. An Extract is a snapshot saved in Tableau's .hyper format; it is faster on big data and is what Tableau Public uses when you publish.

2. Check the field types

Each column header in the grid has a small icon. Abc means text, # means number and a calendar means date.

  1. Check that Order Date shows a calendar. If it shows Abc, select the icon and pick Date.
  2. Check that Quantity, Unit Price and Discount show #.
  3. Note that Tableau tidies the names. order_date becomes Order Date and store_id becomes Store Id. Your version may capitalise slightly differently. The field is the same.

3. Create the Sales field

  1. Select Sheet 1 at the bottom left to open the worksheet.
  2. Select Analysis > Create Calculated Field.
  3. Name it Sales and type:
[Quantity] * [Unit Price] * (1 - [Discount])
  1. The message under the formula should read that the calculation is valid. Select OK.
  2. Sales appears in the Data pane with =# beside it, below the line with the other measures.
  3. Right-click (Control-click on Mac) Sales in the Data pane, select Default Properties > Number Format, pick Currency (Custom), set decimals to 0 and the prefix to ₹. Every view of Sales now shows rupees.

4. Build the bar chart

  1. Rename the sheet: double-click the Sheet 1 tab and type Sales by store.
  2. Drag Store Id to Columns.
  3. Drag Sales to Rows. The pill reads SUM(Sales) and is green. Tableau draws one bar per store.
  4. Select the Sort Descending button on the toolbar. The tallest bar moves left.
  5. Drag Sales again, this time onto Label on the Marks card. Each bar shows its value.

5. Build the line chart

  1. Select the New Worksheet tab at the bottom (the icon beside your sheet tab). Name it Sales by month.
  2. Drag Order Date to Columns. It arrives blue as YEAR(Order Date).
  3. Right-click the pill. The menu has two groups of date options. Pick Month in the lower group, the one whose example shows a month with a year. The pill turns green and reads MONTH(Order Date). That is a continuous date: a real timeline.
  4. Drag Sales to Rows. Tableau draws a line.
  5. Look at the bottom right of the view. A small indicator reads 1 null. That is the order dated 2026-09-31. September has 30 days, so Tableau cannot place the row on a timeline.

6. Add a filter to both sheets

  1. Go back to Sales by store. Drag Store Id to the Filters shelf.
  2. In the dialog, clear the tick beside ST-099 and select OK. ST-099 is not in the Harbour Goods store list; it is a keying error.
  3. Right-click the Store Id pill on Filters and select Apply to Worksheets > All Using This Data Source. The pill gains a small icon to show it is shared.
  4. Right-click the pill again and select Show Filter. A list of tick boxes appears on the right. The reader can now drop any store.
  5. Switch to Sales by month. The same filter is there and ST-099 is gone from the line too.

7. Save it

Select File > Save As and pick Tableau Packaged Workbook (.twbx), which bundles the data with the workbook so someone else can open it. In Desktop Public Edition you can save locally the same way, or select File > Save to Tableau Public As when you are ready to publish. Anything on Tableau Public is visible to everyone.

After the filter, six bars total ₹155,416. The line chart shows July 68,683.50, August 43,961.60 and September 40,725.75, with ₹2,899 parked under the null date. The three months plus that null add back to the grand total.

To check the total in Tableau, select Analysis > Totals > Show Row Grand Totals on the bar chart. A Grand Total bar appears.

Where this breaks

  • HG-40017 appears twice. Two identical rows, one order. Tableau sums both, so ST-014 is ₹549 higher than it should be. Tableau will not warn you. COUNTD(Order Id) gives 59 orders against 60 rows; that gap is your clue.
  • HG-40056 has no quantity. Sales for that row is Null and SUM skips it. That is the right answer for a total but the wrong one for an average. The calculated fields step fixes it with ZN().
  • HG-40057 has a quantity of minus 2. Probably a return keyed into the sales file. It lowers ST-003 by ₹1,098. Whether it belongs is a business question, not a Tableau one.
  • The impossible date. If your Tableau version reads Order Date as text because of that row, change its type on the data source page. The null indicator is the safety net, not the fix.
  • Filter on the wrong sheet. A filter added to one sheet stays on that sheet unless you apply it to others. If two sheets disagree on a total, check the Filters shelf on each.

Which chart when

A bar compares categories. A line shows change over time. When you are not sure, use the site's chart chooser.

On the brewhouse floor

A brewery's packaging log has the same shape: date, line, product, cases packed. Sales by store becomes cases by packaging line. The line chart becomes cases per week. The messy rows look familiar too. A shift enters the same pallet twice, a blank where a case count should be and a minus number that was really a rework. Build the bar and the line first. Then ask the shift lead about the odd rows, because the chart shows you where to look but the floor knows why.
