Tableau Agent and Explain Data: use both, then check both

Build a view and a calculation with Tableau Agent in web authoring, run Explain Data on the mark that dropped. Then catch what each one got wrong on the Harbour Goods orders.

12 Oct 2026 Tableau as of October 2026 Checked against Tableau Help Level 2 Ankur Napa AICloudDesktop

Short answer

Tableau Agent turns a sentence into a view or a calculation. Explain Data builds statistical models around one mark and proposes what might be behind its value. They are different machines. Tableau Agent is generative and guesses at the defaults you leave out: date level, aggregation, what "top" means. Explain Data is statistics and cannot tell you a cause. Use each for what it is good at, write down the number you expect before you ask and compare. This build shows one wrong default from the Agent and one plausible explanation from Explain Data that is pure noise.

What you will build

A web authoring workbook on the Harbour Goods Orders published data source with three sheets. The first is net sales by region for July to September 2026, built by Tableau Agent. The second holds a Discount Amount calculation that Tableau Agent writes and then explains. The third is a store by quarter bar chart where you run Explain Data on Pune's fall.

Use the same data source as Your first Pulse metric: first-pulse-metric-net-sales.csv, published to Tableau Cloud as an extract. It has 105 orders from April to September 2026 with Order Date, Store Id, City, Region, Category, Quantity, Unit Price, Discount and Net Sales. April to June is synthetic, generated from a fixed random seed. Remember that; it matters in step 4.

Before you start

  • Tableau Cloud with Tableau+ or a trial, with AI in Tableau turned on in site settings. On Tableau Server, Tableau Agent needs 2025.3 or later with AI in Tableau configured against your own LLM provider.
  • Site role Creator or Explorer for Tableau Agent in web authoring.
  • Tableau Desktop works too: Tableau Agent is in Desktop from 2025.1 when you are signed in to a Cloud site that meets the requirements. The help page for Desktop lists Tableau Cloud+ or Tableau+.
  • Run Explain Data capability on the workbook. Explain Data is on by default for a site and an administrator can turn it off.
  • Hide fields you will not use. Tableau Agent indexes captions, descriptions and up to 1,000 sample values per string field. Similar names confuse it.

Steps

1. Open Tableau Agent

  1. In Tableau Cloud open the data source page for Harbour Goods Orders and select New > Workbook, or open an existing workbook and select Edit.
  2. Select the Tableau Agent icon in the toolbar next to Show Me.
  3. Read the disclaimer and select Got It.

If the icon is missing, one of the requirements above is not met. The icon only appears when they all are.

2. Ask for a view and say what you know

Type this exactly:

Show net sales by region as a bar chart, sorted from highest to lowest.

Tableau Agent builds a bar chart with Region on Rows and SUM(Net Sales) on Columns, sorted descending.

Check. Write down the totals before you read the bars. Across all 105 orders: West 137,422.35, South 118,183.35, North 89,056.95 and East 36,141.25. That is what the Agent built. It is correct for the question typed and wrong for the question meant. The manager wanted last quarter. The prompt never said so and the Agent did not ask; the help page says plainly that it does not ask clarifying questions and may guess at defaults such as date level.

Now say what you know:

Filter to orders from 1 July 2026 to 30 September 2026.

Check. The bars should now read South 59,942.45, West 48,197.10, North 32,640.90 and East 12,285.35. South moves to the top. If the Agent added YEAR(Order Date) = 2026 instead, the bars will not change, because every order is in 2026. Look at the Filters shelf, not just the bars. Select Recreate to go back a step if a request goes wrong, or Retry with Tableau Agent for a fresh attempt.

3. Write and explain a calculation

Create a calculation called Discount Amount: quantity times unit price times
discount.

Tableau Agent opens the calculation editor with something close to:

[Quantity] * [Unit Price] * [Discount]

Select OK. Creating a calculation and using it in a view are two separate requests; the Agent does not do both in one step. Drag Discount Amount to the view yourself, then ask the Agent to explain an existing calculation. Open Net Sales in the calculation editor and use the Tableau Agent bar at the top of the editor to ask for an explanation.

Check. With the July to September filter, SUM(Discount Amount) is 6,831.20, which is 4.27% of gross sales. April to June is 9,786.90 or 4.12%. If the number is far too large, look for SUM() around each field inside the formula. Multiplying three sums is not the sum of the products; the formula must stay row level.

4. Run Explain Data on the fall

  1. Start a new sheet. Put Store Id on Columns, QUARTER(Order Date) as a discrete (blue) pill on Columns after it. Put SUM(Net Sales) on Rows.
  2. Pune, ST-014, drops from 68,235.25 in Q2 to 29,266.75 in Q3, the biggest fall on the chart. Select the Q3 bar for ST-014.
  3. Select the Data Guide icon in the toolbar, or hover over the bar and select the Data Guide icon in the tooltip menu. In Tableau Public it is a lightbulb.
  4. Expand each explanation in the Data Guide pane.

Expect explanations along these lines: fewer records behind the mark (11 orders against 16) and categories that contributed less (Electronics fell from 25,497.30 to 9,195.00 and Kitchen from 18,700.50 to 3,320.25). The exact explanation names vary by version.

Check. Every one of those numbers is true. None of them is a reason. April to June in this file came out of a random number generator. Explain Data found structure in noise because that is what statistical explanations do with 27 orders. The help page is blunt: Explain Data cannot identify causes and "you are the expert on your data". In real data, take each explanation as a question for the store manager, not an answer for the board.

Explain Data needs the measure aggregated with SUM, AVG, COUNT, COUNTD or an AGG calculation, a single primary data source and no blends or cubes.

Where this breaks

  • Missing context in the prompt. Date range, aggregation and sort measure are the usual gaps. Name them every time.
  • Things the Agent does not do. No joins or relationships, no data type or role changes, no groups, sets or parameters, no reference lines, no dashboard building, no filter controls or actions, no cubes. With a blend it uses only the primary source.
  • Tableau Agent on Server is a different trust model. On Cloud, prompts go through the Einstein Trust Layer with zero data retention and optional PII masking. On Server you connect your own provider: OpenAI, or Azure OpenAI from 2026.2. Tableau sends the question plus a small sample of field values. PII masking on the provider side is yours.
  • Explain Data on small numbers. Under a few dozen records per mark, treat every explanation as a coincidence until proven otherwise.
  • Dashboard features. Tableau Agent in dashboards is in beta from 2026.1 on Cloud only. Viewers need extra permissions. Do not design a process around a beta.

On the brewhouse floor

Run Explain Data on the week a lager's attenuation dropped and it may say the low batches share a yeast generation and a fermenter. Both are true on the sheet. Whether the cause is tired yeast, a cold jacket or a hydrometer read at the wrong temperature is a walk to the cellar, not a click. Tableau Agent will happily build the attenuation chart; tell it the date range and the aggregation or it will average the averages. My quality control charts for brewing use Explain Data on out-of-control points in exactly this spirit.
