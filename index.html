Tableau Desktop, level 0: Foundations

What each Tableau product is, how a viz is built from pills and who the community is.

  1. The Tableau family in one picture Place Desktop, Prep, Server, Cloud, Public, Pulse and Next in one map. Certification: Foundations
  2. Blue pills and green pills Tell dimensions from measures and discrete from continuous. Learn why the colour matters. Certification: Foundations
  3. Shelves, the Marks card and Show Me Read any worksheet by its Columns, Rows and Marks. Certification: Foundations

Tableau Desktop, level 1: Beginner

Your first workbook, flow, published viz and API call.

  1. Your first workbook Connect a CSV, build a bar and a line chart and add a filter. Certification: Foundations
  2. Dates done right Choose date parts or date values and get continuous time on an axis. Certification: Foundations
  3. Calculated fields Write row-level and aggregate calculations with IF, CASE and ZN. Certification: Foundations, Data Analyst
  4. Quick table calculations Add running totals, percent of total and year-over-year change. Certification: Foundations
  5. Maps with geographic roles Map cities and regions, fix unknown locations and pick filled or symbol maps. Certification: Foundations
  6. Your first dashboard Lay out sheets in containers, set a fixed size and add a filter action. Certification: Foundations, Data Analyst

Tableau Desktop, level 2: Practitioner

Certification depth. LODs, table calcs, security, embedding and MCP.

  1. LOD expressions Use FIXED, INCLUDE and EXCLUDE and know which filters they ignore. Certification: Data Analyst
  2. Table calcs: addressing and partitioning Control Compute Using so a table calculation means what you think. Certification: Data Analyst
  3. The order of operations Predict when extract, data source, context, dimension and measure filters apply. Certification: Data Analyst
  4. Parameters and parameter actions Let readers swap measures, set targets and drive what-if analysis. Certification: Data Analyst
  5. Sets and set actions Build top N, in or out comparisons and drill-downs with set actions. Certification: Data Analyst
  6. Charts beyond Show Me Build dual-axis, bullet, Pareto and waterfall charts. Certification: Data Analyst
  7. Relationships and multi-fact models Model with relationships, know when a physical join is still right and avoid blends. Certification: Data Analyst

Tableau Desktop, level 3: Professional

Production habits: performance, accessibility, monitoring and automation.

  1. Fix a slow workbook Find the slow query or render with the Performance Recorder and prove the fix. Certification: Consultant
  2. Accessible dashboards Meet contrast, keyboard and screen-reader needs in a published dashboard.
  3. A dashboard design system Ship a team template, colour palette and layout grid that keep dashboards consistent.

Tableau Desktop, level 4: Architect

Deployment, identity, governance, embedded products and community leadership.

  1. One KPI, one definition Keep a metric identical across workbooks, data sources and Pulse. Certification: Consultant

Tableau Prep, level 0: Foundations

What each Tableau product is, how a viz is built from pills and who the community is.

  1. Why Prep exists Know when to clean in Prep, in Desktop or upstream. Read the flow and profile panes. Certification: Data Analyst

Tableau Prep, level 1: Beginner

Your first workbook, flow, published viz and API call.

  1. Your first Prep flow Clean, join and union files, then output a Hyper extract. Certification: Data Analyst

Tableau Prep, level 2: Practitioner

Certification depth. LODs, table calcs, security, embedding and MCP.

  1. Pivots, aggregates and calculations in Prep Reshape wide data, aggregate and write fixed LOD and rank calculations in a flow. Certification: Data Analyst
  2. Schedule flows with Prep Conductor Publish a flow, schedule it and use incremental refresh. Certification: Data Analyst, Server Administrator

Tableau Prep, level 3: Professional

Production habits: performance, accessibility, monitoring and automation.

  1. Prep at scale Speed up big flows, use parameters and keep flows under version control.

Tableau Prep, level 4: Architect

Deployment, identity, governance, embedded products and community leadership.

  1. Governed data at scale Combine virtual connections, data policies, certification and Catalog lineage. Certification: Architect

Tableau Server and Cloud, level 0: Foundations

What each Tableau product is, how a viz is built from pills and who the community is.

  1. Server, Cloud and the three licences Explain Tableau Server against Tableau Cloud and what Creator, Explorer and Viewer can do. Certification: Server Administrator

Tableau Server and Cloud, level 1: Beginner

Your first workbook, flow, published viz and API call.

  1. Publish and share Publish a workbook, set project permissions and share a link with the least access that works. Certification: Data Analyst, Server Administrator

Tableau Server and Cloud, level 2: Practitioner

Certification depth. LODs, table calcs, security, embedding and MCP.

  1. Row-level security Apply user filters, entitlement tables and data policies that hold. Certification: Data Analyst, Consultant
  2. Published data sources and refresh schedules Publish one certified source many workbooks share and schedule its extract. Certification: Data Analyst, Server Administrator

Tableau Server and Cloud, level 3: Professional

Production habits: performance, accessibility, monitoring and automation.

  1. Sites, projects and the permission model Design groups, locked projects and permission rules that scale. Certification: Server Administrator, Consultant
  2. Monitor usage and health Read Admin Insights, Activity Log or the Server repository to see who uses what. Certification: Server Administrator
  3. Extracts and backgrounder load Balance refresh schedules, incremental extracts and backgrounder capacity. Certification: Server Administrator, Architect

Tableau Server and Cloud, level 4: Architect

Deployment, identity, governance, embedded products and community leadership.

  1. Cloud or Server: the deployment decision Choose between Tableau Cloud and Server with a trade-off table, not a hunch. Certification: Architect
  2. Server topology and scaling Size nodes and processes for interactive and background load. Certification: Architect
  3. Identity, SSO and private data Design SAML or OIDC, SCIM and Tableau Bridge for data behind the firewall. Certification: Architect, Consultant
  4. Migrate Server to Cloud Plan a migration with the Content Migration Tool, a pilot and a cutover. Certification: Architect
  5. Running a centre of excellence Apply Tableau Blueprint to governance, enablement and adoption. Certification: Consultant, Architect

What each Tableau product is, how a viz is built from pills and who the community is.

Tableau Public and community, level 1: Beginner

Your first workbook, flow, published viz and API call.

Tableau Public and community, level 2: Practitioner

Tableau Public and community, level 3: Professional

Production habits: performance, accessibility, monitoring and automation.

  1. Iron Viz Enter the qualifier with a story, a design and analysis the judges reward.
  2. Speak at a user group Turn a project into a twenty-minute session people learn from.

Tableau Public and community, level 4: Architect

Deployment, identity, governance, embedded products and community leadership.

  1. Lead a community Run a user group. See what the Ambassador and Visionary programmes ask of you.

Developer access, level 0: Foundations

What each Tableau product is, how a viz is built from pills and who the community is.

  1. Developer access and the API map Join the Developer Program and see which API does what: REST, Embedding, Extensions, Hyper, Metadata.

Developer access, level 1: Beginner

Your first workbook, flow, published viz and API call.

  1. Sandbox and your first REST call Get a developer sandbox site, sign in with a personal access token and list workbooks.

Developer access, level 2: Practitioner

Certification depth. LODs, table calcs, security, embedding and MCP.

  1. Embed a viz with the Embedding API Embed with the v3 web component and sign users in with a connected app.
  2. Automate with Tableau Server Client Script publishing, refreshes and permissions in Python with TSC.

Developer access, level 3: Professional

Production habits: performance, accessibility, monitoring and automation.

  1. Dashboard extensions Build a dashboard extension with the Extensions API and run it safely.
  2. Build extracts with the Hyper API Create and update .hyper files from code and publish them.
  3. Lineage with the Metadata API Query content and lineage with GraphQL to find what breaks when a column changes.

Developer access, level 4: Architect

Deployment, identity, governance, embedded products and community leadership.

  1. Embedded analytics as a product Design multi-tenant embedding: sites, row-level security, connected apps and usage licences. Certification: Architect

AI, Pulse and MCP, level 0: Foundations

What each Tableau product is, how a viz is built from pills and who the community is.

AI, Pulse and MCP, level 1: Beginner

Your first workbook, flow, published viz and API call.

  1. Your first Pulse metric Define a metric, follow it and read the digest it sends.
  2. Claude as your calculation partner Use Claude to write, explain and debug calculated fields, LODs and table calcs. Then check its answer.

AI, Pulse and MCP, level 2: Practitioner

Certification depth. LODs, table calcs, security, embedding and MCP.

  1. Tableau Agent and Explain Data Use the authoring agent and Explain Data. Check what each one got wrong.
  2. Connect Claude to Tableau with MCP Run the Tableau MCP server and query a published data source from an AI client.
  3. Claude Code for Tableau automation Have Claude Code write TSC and REST scripts, edit workbook XML safely and review a dashboard against a checklist.

AI, Pulse and MCP, level 3: Professional

Production habits: performance, accessibility, monitoring and automation.

  1. Python and R with analytics extensions Call TabPy from a calculation and know when it is the wrong tool.
  2. MCP in production Scope tokens, pick connected app or PAT auth and decide which data an agent may query.

AI, Pulse and MCP, level 4: Architect

Deployment, identity, governance, embedded products and community leadership.

  1. Agentic analytics architecture Place Tableau Next, the semantic layer and MCP in one design with governance. Certification: Architect, Tableau Next Consultant
