Build a career on Tableau

Pick the role you want. Each path tells you what to learn and in what order, which certification proves it, what to build for your portfolio and what interviewers will ask.

  1. Pick a role below.
  2. Follow its steps on the roadmap and tick them off.
  3. Earn the certification that matches.
  4. Build the portfolio project and publish it.
  5. Practise the interview questions.

Tableau developer

Builds the dashboards people open every morning. Owns the calculations, the layout, the performance and the moment someone asks why the number moved.

Learning path, in order

  1. 0 The Tableau family in one picture Foundations
  2. 0 Blue pills and green pills Foundations
  3. 0 Shelves, the Marks card and Show Me Foundations
  4. 1 Your first workbook Beginner
  5. 1 Dates done right Beginner
  6. 1 Calculated fields Beginner
  7. 1 Quick table calculations Beginner
  8. 1 Your first dashboard Beginner
  9. 2 LOD expressions Practitioner
  10. 2 Table calcs: addressing and partitioning Practitioner
  11. 2 Parameters and parameter actions Practitioner
  12. 2 Sets and set actions Practitioner
  13. 2 Charts beyond Show Me Practitioner
  14. 2 A portfolio that gets you hired Practitioner
  15. 3 Fix a slow workbook Professional
  16. 3 Accessible dashboards Professional
  17. 3 A dashboard design system Professional

Certifications

  • Foundations Salesforce Certified Tableau Desktop FoundationsThe entry exam. Proves you can build and read a worksheet in Tableau Desktop.
  • Data Analyst Salesforce Certified Tableau Data AnalystThe working analyst exam across Desktop, Prep and Server or Cloud.

Portfolio project

A store performance dashboard for Harbour Goods: sales against target by region, a parameter to swap measures, a set action to compare the top ten stores, a mobile layout and a one-page note on the performance fixes you made.

Interview questions to master

  • What is the difference between a blue pill and a green pill? Why does it change the chart?
  • Walk me through FIXED, INCLUDE and EXCLUDE with an example from your own work.
  • A table calculation gives the wrong running total. How do you debug it?
  • Where does a context filter sit in the order of operations? When would you use one?
  • A dashboard takes twenty seconds to load. What do you check first?
  • How do you make a dashboard usable with a keyboard and a screen reader?
  • When would you use a parameter action instead of a filter action?

Data analyst with Tableau

Starts from the business question, cleans the data in Prep and answers in Desktop. The dashboard is the output; the reasoning is the job.

Learning path, in order

  1. 0 Blue pills and green pills Foundations
  2. 0 Why Prep exists Foundations
  3. 1 Your first workbook Beginner
  4. 1 Dates done right Beginner
  5. 1 Calculated fields Beginner
  6. 1 Quick table calculations Beginner
  7. 1 Your first Prep flow Beginner
  8. 1 Publish and share Beginner
  9. 1 Your first Pulse metric Beginner
  10. 1 Claude as your calculation partner Beginner
  11. 2 Pivots, aggregates and calculations in Prep Practitioner
  12. 2 LOD expressions Practitioner
  13. 2 Table calcs: addressing and partitioning Practitioner
  14. 2 The order of operations Practitioner
  15. 2 Relationships and multi-fact models Practitioner

Certifications

  • Data Analyst Salesforce Certified Tableau Data AnalystThe working analyst exam across Desktop, Prep and Server or Cloud.

Portfolio project

A returns analysis for Harbour Goods: a Prep flow that cleans and joins orders with returns, a relationship model, three LOD-driven views that explain which products come back and why plus a Pulse metric for the return rate.

Interview questions to master

  • How do you decide whether to clean data in Prep, in Desktop or upstream?
  • Explain relationships against joins. When is a physical join still right?
  • Two data sources disagree on revenue. How do you find out which is right?
  • How would you show year-over-year change for a product that did not sell last year?
  • What does a FIXED LOD ignore? What does it respect?
  • How do you present an analysis to someone who will not open the dashboard?

Tableau Server and Cloud administrator

Keeps the platform fast, secure and boring. Owns sites, permissions, extract schedules, upgrades and the Monday morning refresh that failed.

Learning path, in order

  1. 0 Server, Cloud and the three licences Foundations
  2. 1 Publish and share Beginner
  3. 2 Row-level security Practitioner
  4. 2 Published data sources and refresh schedules Practitioner
  5. 2 Schedule flows with Prep Conductor Practitioner
  6. 2 Automate with Tableau Server Client Practitioner
  7. 3 Sites, projects and the permission model Professional
  8. 3 Monitor usage and health Professional
  9. 3 Extracts and backgrounder load Professional
  10. 4 Server topology and scaling Architect
  11. 4 Identity, SSO and private data Architect

Certifications

  • Server Administrator Salesforce Certified Tableau Server AdministratorInstalling, securing and running a single-node Tableau Server.

Portfolio project

An admin runbook for Harbour Goods: a site and project structure with locked permissions, a refresh schedule that spreads backgrounder load, a usage report from the admin views and a TSC script that lists stale content.

Interview questions to master

  • Explain what Creator, Explorer and Viewer can each do.
  • How do you design project permissions so they stay manageable at a thousand users?
  • Extract refreshes are queuing every morning. How do you fix it?
  • How do you back up and restore Tableau Server? How often do you test the restore?
  • Which admin views or repository tables tell you who uses what?
  • What changes when you move from Server to Cloud?
  • How do you automate user and group sync?

Tableau consultant

Walks in, works out what the customer actually needs and leaves them better at Tableau. Design, performance, security and adoption are all on the table.

Learning path, in order

  1. 2 LOD expressions Practitioner
  2. 2 The order of operations Practitioner
  3. 2 Relationships and multi-fact models Practitioner
  4. 2 Row-level security Practitioner
  5. 2 Tableau Agent and Explain Data Practitioner
  6. 3 Fix a slow workbook Professional
  7. 3 A dashboard design system Professional
  8. 3 Sites, projects and the permission model Professional
  9. 3 Speak at a user group Professional
  10. 4 Running a centre of excellence Architect
  11. 4 One KPI, one definition Architect

Certifications

  • Data Analyst Salesforce Certified Tableau Data AnalystThe working analyst exam across Desktop, Prep and Server or Cloud.
  • Consultant Salesforce Certified Tableau ConsultantDesign, performance, scale, adoption and governance, judged across the whole stack.

Portfolio project

An assessment pack for Harbour Goods: a review of three existing dashboards with before and after versions, a row-level security design, a performance report and a one-page adoption plan built on Tableau Blueprint.

Interview questions to master

  • A customer wants one dashboard for everyone. How do you respond?
  • Walk me through how you would review a slow workbook you did not build.
  • Compare user filters, entitlement tables and data policies for row-level security.
  • How do you get one KPI to mean the same thing in every workbook?
  • What does a centre of excellence actually do in its first ninety days?
  • Tell me about a time you pushed back on a stakeholder request.

Embedded analytics developer

Puts Tableau inside other products. Lives in the Embedding API, connected apps, the REST API and the question of which customer sees which row.

Learning path, in order

  1. 0 Developer access and the API map Foundations
  2. 1 Sandbox and your first REST call Beginner
  3. 2 Embed a viz with the Embedding API Practitioner
  4. 2 Automate with Tableau Server Client Practitioner
  5. 2 Row-level security Practitioner
  6. 2 Connect Claude to Tableau with MCP Practitioner
  7. 3 Dashboard extensions Professional
  8. 3 Build extracts with the Hyper API Professional
  9. 3 Lineage with the Metadata API Professional
  10. 3 MCP in production Professional
  11. 4 Embedded analytics as a product Architect

Certifications

  • Data Analyst Salesforce Certified Tableau Data AnalystThe working analyst exam across Desktop, Prep and Server or Cloud.
  • Architect Salesforce Certified Tableau ArchitectDesigning, deploying and keeping a scalable Tableau platform healthy.

Portfolio project

A supplier portal for Harbour Goods: an embedded dashboard behind a connected app, row-level security so each supplier sees only their products, a Hyper API job that refreshes the extract and a short note on licence costs.

Interview questions to master

  • How does a connected app sign a user in to an embedded view?
  • How do you keep tenant data apart in a multi-tenant embed?
  • When would you use the Hyper API instead of a scheduled extract refresh?
  • What can the Metadata API tell you before you change a column?
  • How do you handle filters and events between the host page and the viz?
  • What would you let an AI agent query through the Tableau MCP server? What would you block?

Tableau architect

Designs the platform and owns the decisions nobody wants to revisit: Cloud or Server, identity, topology, governance and where Tableau Next fits.

Learning path, in order

  1. 3 Sites, projects and the permission model Professional
  2. 3 Extracts and backgrounder load Professional
  3. 3 MCP in production Professional
  4. 4 Cloud or Server: the deployment decision Architect
  5. 4 Server topology and scaling Architect
  6. 4 Identity, SSO and private data Architect
  7. 4 Migrate Server to Cloud Architect
  8. 4 Running a centre of excellence Architect
  9. 4 Governed data at scale Architect
  10. 4 Embedded analytics as a product Architect
  11. 4 Agentic analytics architecture Architect

Certifications

  • Server Administrator Salesforce Certified Tableau Server AdministratorInstalling, securing and running a single-node Tableau Server.
  • Architect Salesforce Certified Tableau ArchitectDesigning, deploying and keeping a scalable Tableau platform healthy.
  • Tableau Next Consultant Salesforce Certified Tableau Next ConsultantThe newest exam. Tableau Next, semantic models and Data Cloud inside Salesforce.

Portfolio project

A target architecture for Harbour Goods: a Cloud or Server decision table, an identity design with SSO and SCIM, a Bridge plan for on-premises data, a migration wave plan and a governance model for certified data sources.

Interview questions to master

  • Cloud or Server for a retailer with on-premises data? Walk me through the trade-offs.
  • How do you size a Server deployment for both interactive and background load?
  • Design SSO and user provisioning for ten thousand users.
  • How do you plan a Server to Cloud migration with no downtime for executives?
  • What makes a data source certified? Who decides?
  • Where do Tableau Next and the semantic layer fit next to existing workbooks?
  • How would you govern AI agents querying Tableau data?
